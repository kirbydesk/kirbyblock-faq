# kirbyblock-faq

FAQ block for [kirby-pagewizard](https://github.com/kirbydesk/kirby-pagewizard):
questions with answers that fold open, marked up for search engines
(Schema.org FAQPage as JSON-LD).

- **Behaviour** (per block, start value in the Project Wizard): several
  open, one at a time (the browser closes the others, no JavaScript), or
  always open; optionally the first question open.
- **Style** (per block): lines between the questions or each question a
  card.
- **Layout**: the intro above the questions or beside them (from 1024 px).
- **Design** (Project Wizard): icon (chevron, plus, none), its position,
  size and stroke, dividers, answer width, paddings and gaps, colours per
  variant; question and answer in the type of Elements › Items.
- **Answer**: the project's editor (text field and/or writer).

## Requirements

- kirby-pagewizard ^1.1.54
- kirby-projectwizard ^1.0
